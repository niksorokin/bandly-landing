# V57 scope

V57 is an isolated version: the V54 design with V55's Inter. It is a copy of the current live site, not a replacement for it. V1–V56 and their published version routes remain unchanged.

- One family everywhere: Inter (`opsz,wght@14..32,100..900`). Instrument Serif and JetBrains Mono are removed.
- Former serif text (display, headlines, service names, stats, calculator amount, dialog titles, proof quote) keeps its V54 sizes, set in Inter 460 at -0.02em.
- Former mono text (eyebrows, step numbers, meta, pills, file names, row labels) keeps its V54 sizes and uppercase, set in Inter 500 with tabular numerals on changing numbers.
- Body is Inter 16px, weight 460, line-height 1.5, antialiased.
- No changes to color, layout, photos, the Unicorn hero, copy, the intake form, or `fetch('/api/intake')`.
